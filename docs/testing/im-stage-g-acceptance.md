## 4. 真实验收的前置条件

1. 部署 `f86881a` 或之后的文档提交，`AGENTFLOW_PUBLIC_URL` 可从试点成员浏览器访问（网页确认链接依赖它）。
2. 飞书应用已开通“以应用的身份发消息”；钉钉应用开通机器人发送单聊消息的权限（见手册第 4A.1 节）。
3. 至少一名已在飞书、钉钉 Bot 单聊中完成绑定的成员；一个企微 Bot 和一名已绑定的成员。
