# LoopForge 知识库配置与使用操作手册（一期）

本手册适用于已完成部署的 LoopForge 平台（接入 WeKnora 知识库引擎），覆盖**知识库接入配置、WeKnora 文档准备、项目权限隔离、AI 对话引用、SOP 节点绑定、知识沉淀回写与排障调试**全流程。

---

## 一、配置知识库接入（平台管理员）

进入 LoopForge 控制台左侧边栏：**`设置 → 知识中心 → 接入配置与用量`**。

### 方式 A：新建内置 WeKnora 实例（单机一键开启）
1. 在 **「快速接入 WeKnora（一键开启）」** 卡片中，选择 **`新建内置 WeKnora 实例`**；
2. 点击 **`一键启动并接入 WeKnora`**；
3. 系统会自动在同 Docker 网络拉起内置 WeKnora 服务（端口 `18080` / 控制台 `18081`），完成默认空间初始化（默认账号：`admin@loopforge.local`，密码取部署环境变量 `LOOPFORGE_WEKNORA_ADMIN_PASSWORD`；未设置时才是 `LoopForge@2026!`）并自动签发 `X-API-Key` 写入知识中心。控制台登录凭据可在知识中心「登录凭据」中查看。

### 方式 B：链接已有 WeKnora 实例（支持多空间 / 跨节点部署）
1. 选择 **`链接已有 WeKnora 实例`**；
2. 填写以下信息：
   - **连接名称**（可选）：用于区分多个实例或空间（如 `研发空间`、`测试空间`）；
   - **已有 WeKnora 地址**：
     - 同机容器互联：填 `http://weknora-app:8080` 或 `http://172.17.0.1:8080`（浏览器点击「管理此知识库 ↗」时会自动重写为 `<当前访问主机>:18081`）；
     - 跨节点部署：**请填写目标机器的 WeKnora 前端/网关地址**（如 `http://10.0.0.12:18081`、`http://10.0.0.12:80` 或 `https://weknora.example.com`）。因为 WeKnora 前端 Nginx 同时提供 Web 界面与 `/api/v1/*` 接口反代，填写前端地址可确保「Agent 检索」与浏览器点击「管理此知识库 ↗」使用同一个 URL 均能正常工作（若仅填跨节点的 `:8080` 纯后端 API 端口，浏览器点击「管理此知识库 ↗」会因无前端页面返回 404）；
   - **认证凭据（二选一）**：
     - 方式 1：直接填入 WeKnora 的 **`API Key`**（`sk-...`）；
     - 方式 2：留空 API Key，填写 **WeKnora 登录邮箱 + 密码**，由 LoopForge 自动登录并签发专属 API Key；
3. 点击 **`一键链接并追加保存`**。新增连接会追加至下方 **「已连接的知识库实例」** 列表，不会覆盖已有连接，支持多账号/多实例聚合。

## 二、在 WeKnora 控制台准备知识库与文档

LoopForge 的 **`知识库与文档`** 页面用于只读展示与分块预览，实际建库、上传和编辑统一在 WeKnora 控制台完成：

1. 在 **`知识中心 → 知识库与文档`** 选中任一知识库，点击右上角 **`高级配置 ↗`** 进入对应的 WeKnora 控制台（页面副标题会提示该连接对应的登录邮箱）；
   - **平台管理员可免密进入**：点击后平台用该连接保存的账号签发一张 60 秒、仅可使用一次的票据，由内置实例上的同源桥接页自动写入登录态，无需再输入密码；同一实例上切换连接（例如从 `editor@example.com` 换到 `admin@loopforge.local`）会自动覆盖上一次的登录，不会沿用旧账号。
   - 非管理员、外部实例（地址不等于内置 `LOOPFORGE_WEKNORA_URL`）或尚未保存密码的账号不会走免密：仍会打开控制台，由使用者手动登录；未保存密码时界面会提示先到 **`登录凭据`** 中填写并保存。
2. **绑定模型（必做）**：在 WeKnora 知识库设置中为知识库绑定可用的 **Embedding 模型** 与摘要模型，否则上传文档会解析失败；
3. **导入文档**：在 WeKnora 上传 Markdown、PDF、DOCX 等文档或导入网页 URL；
4. **确认状态**：回到 LoopForge **`知识中心 → 知识库与文档`** 点击刷新，确认文档解析状态为绿色 **`已解析`**（若显示 **`解析失败`**，可点击旁边的 **`原因`** 查看具体报错）。

## 三、配置项目级授权范围（可选，权限隔离）

若希望限制某个 LoopForge 项目只能访问指定的部分知识库：

1. 在顶部项目切换器选择目标项目；
2. 进入 **`知识中心 → 接入配置与用量`**；
3. 在 **「上游知识库接入配置 → 当前项目授权知识库范围」** 中，勾选允许该项目访问的知识库（不勾选表示允许访问全部）；
4. 确认勾选 **`启用平台知识库`**（以及按需勾选 **`允许审核后写回`**），点击 **`保存配置`**。

---

## 四、在 AI 工作台（对话）中关联使用

1. 进入 **`AI 工作台`** 新建或打开一个对话；
2. 点击输入框工具栏中的 **`关联知识库`** 按钮；
3. 在弹窗中勾选 **`团队知识库（WeKnora）`**：
   - **全部范围**：在「可检索范围」选择 **`当前身份可读的全部来源`**；
   - **精准限定**：选择 **`仅指定来源`**，并在「选择知识库」列表中直接勾选需要的 1 个或多个知识库（右下角会实时显示 `已选 N 个知识库`）；
4. 点击 **`保存`**；
5. 发送提问后，Agent 会自动只读检索所选知识库，回答上方折叠栏会实时展示**检索词、命中文档及引用状态**。

## 五、在 SOP 流程中关联使用

### 1. 为 SOP Agent 节点绑定知识库
1. 进入 **`流程模板 / 流程设计`**，打开目标 SOP 并选中需要检索知识的 **Agent 节点**；
2. 在右侧属性面板点击 **`关联知识库`**；
3. 勾选 **`团队知识库（WeKnora）`**，设置「可检索范围」（全部或仅指定某几个知识库），点击 **`保存`** 并保存 SOP；
4. *(可选)* 也可在 **`角色定义`** 中打开该角色的「接入团队知识库」全局开关，使其默认具备项目内知识库检索能力。

### 2. 查看运行时检索与引用轨迹
1. 在 **`需求列表`** 创建需求并触发该 SOP；
2. 进入 **`运行记录`** 打开对应 Run 详情，点击该 Agent 节点：
   - 可在实时轨迹中查看每次检索的工具调用（`list_knowledge_bases`、`search_knowledge`、`read_document`）、检索词、命中目标文档与引用状态；
   - Agent 输出产物中会自动附带原文出处及 `[[knowledge:<id>]]` 引用标记。

## 六、SOP 知识沉淀写回闭环

当 SOP 运行在工作区根目录产出了可复用的 **`knowledge.md`** 交付物时，可审核后写回 WeKnora：

1. 进入 **`知识中心 → 知识沉淀`**；
2. 在 **「SOP 知识候选（knowledge.md）」** 列表中找到对应产物，点击 **`加入审核队列`**；
3. 在下方 **「知识沉淀审核队列」** 点击 **`审核 / 详情`** 打开右侧抽屉：
   - 核对或修改标题、Markdown 正文；
   - 在「写入目标知识库」下拉框选择要写回的 WeKnora 知识库；
4. 点击 **`通过并发布`**，系统会调用 WeKnora 接口自动创建并发布该文档，触发切片建索引，后续对话和 SOP 即可检索到这条新沉淀的知识。

---

## 七、排障调试（管理员自查）

当对话或 SOP 未能命中预期知识时，可进入 **`知识中心 → 排障调试`** 快速定位：

1. 输入要测试的问题或关键词，勾选目标知识库后点击 **`执行检索`**；
2. **判断依据**：
   - **这里搜不到**：检查 WeKnora 控制台文档是否 **`已解析`**、Embedding 模型额度/配置是否正常；
   - **这里能搜到但对话/SOP 没用上**：检查是否在对话工具栏或 SOP Agent 节点中勾选绑定了 **`团队知识库（WeKnora）`**，或项目授权范围是否误排除了目标知识库；
3. 点击任意命中片段的 **`查看原文分块`**，可核对切片内容是否完整。
