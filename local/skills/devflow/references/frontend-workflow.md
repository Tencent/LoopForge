# 前端流程

1. 从清单和锁文件识别框架、包管理器、设计系统与真实脚本，以项目现有约定为准。
2. 覆盖加载、空数据、错误、禁用、权限和异步竞态状态；交互组件检查键盘操作、焦点、语义和必要的可访问性名称。
3. 响应式变更明确关键断点、溢出、长文本和触控行为；设计稿任务同时按 [design-implementation.md](design-implementation.md) 回验视觉证据。
4. 测试按项目现有能力和风险选择组件/DOM、路由或数据集成；项目已有 E2E 且改动影响其关键用户旅程时同步补齐，未配置 E2E 时不强行引入。沿用项目已有类型检查、lint、测试和构建命令。

通用流程、批次、Git 保护和报告规则由核心与阶段规则提供，本 profile 不重复注入。
